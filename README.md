# Command Line Task Manager

A simple and beginner-friendly Command Line Task Manager built using Python.  
This project allows users to manage tasks directly from the terminal with persistent file storage.

---

## Features

- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Save tasks using a text file
- Simple CLI interface

---

## Technologies Used

- Python 3
- File Handling
- Dictionaries
- OS Module
- Command Line Interface (CLI)

## How to Run

### Clone the Repository

```bash
git clone https://github.com/Hacker123488/Command-Line-Task-Manager.git
```

### Move into the Project Folder

```bash
cd Command-Line-Task-Manager
```

### Run the Program

```bash
python task_manager.py
```
